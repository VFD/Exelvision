# The Manuals

___
## Introduction

All documents related to Exelvision hardware are gathered here.\
As for the software, it is provided together with source code, cassette, and disk versions.\
We are working on obtaining high‑quality scans so that reproductions can be made if necessary.\
The goal is to be able to repair items that may be damaged or lost.
